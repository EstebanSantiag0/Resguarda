# Documentos de conocimiento

Resguarda consulta Markdown local dentro de `documents/`; no descarga fuentes durante una conversación.

## Uso rápido

1. Escribe fuentes breves, verificables y con una finalidad concreta.
2. Incluye URL oficial y fecha de revisión en `fuentes.md`.
3. Evita copiar legislación completa: agrega solo orientación comprensible y deja el enlace a la fuente primaria.
4. Prueba cada cambio con una pregunta ficticia antes del demo.

## Regla de seguridad

No incluir datos personales, expedientes reales, capturas reales ni contactos no verificados. El modelo no debe usar estos documentos para determinar delitos o solicitar más datos personales.
